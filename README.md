# MarkFlow Studio

[English](./README.en.md) | **繁體中文**

在電腦上寫 Markdown 文件的編輯器:一邊寫、一邊看排版結果,換個主題就能改變外觀,最後匯出成 **PDF、Word、HTML 或純文字**。

所有處理都在你自己的電腦上進行,文件不會上傳到任何地方。

## 主要功能

- **即時預覽**:左邊寫、右邊看,支援表格、清單、程式碼區塊、連結與圖片
- **多份文件**:分頁切換,每份文件各有自己的復原紀錄;記得你最近開過的檔案
- **外觀可調**:7 種內建主題(白紙、夜間、護眼…),可自訂顏色、字型、字級、行距、頁面寬度並存成自己的主題
- **匯出**:PDF、Word(.docx)、HTML、純文字
- **匯入**:把 HTML 網頁或 Word 文件轉成 Markdown
- **圖片**:文件中引用的圖片可以直接顯示,並一起匯出到 Word、HTML、PDF
- **中英文介面**:繁體中文與 English,一個選單即可切換
- **自動儲存**、**搜尋取代**、**標題大綱**、**字數統計**

## 開始使用

### 一般使用者(Windows)

1. 取得 `MarkFlowStudio-Windows-x64-….zip` 並解壓縮
2. 雙擊 **`MarkFlowStudio.exe`**
3. 幾秒後會出現 MarkFlow Studio 的視窗,直接開始寫

不需要安裝、不需要網路。關閉視窗,程式就會自動結束。需要 Windows 10 或 11(內建的 Edge 或 Google Chrome 都可以)。

**想要一般軟體那樣安裝(開始功能表捷徑、可解除安裝)?** 改用桌面版安裝程式 **`MarkFlowStudio-Setup-v0.1.0.exe`**(約 2 MB):雙擊後安裝到你的使用者資料夾,不需要系統管理員權限。它用 Windows 內建的 WebView2 顯示,所以程式很小,功能與上面完全相同。也可以直接執行不需安裝的 `MarkFlowStudio-Desktop.exe`。

> **第一次執行時 Windows 可能跳出「Windows 已保護您的電腦」。** 這是因為程式沒有購買商業簽章,所有這類程式都會這樣提示。點「**其他資訊**」→「**仍要執行**」即可(請確認檔案來自你信任的人)。

### 從原始碼執行

需要 Node.js 22 以上。

```bash
npm install
npm run dev        # 開發模式,依畫面上的網址用瀏覽器開啟
npm run build      # 產生網頁版(dist/)
npm run package    # 產生 Windows 執行檔與壓縮檔(release/)
npm run desktop    # 產生桌面版安裝程式(需要 Rust 與 Visual Studio 的 C++ 建置工具)
```

建議使用 **Chrome 或 Edge**:可以直接把修改存回原檔。Firefox、Safari 也能使用,但「儲存」會變成下載一份新檔案,且沒有「最近文件」與「圖片資料夾」。

## 基本操作

### 介面語言

工具列最右邊的選單可以在 **繁體中文** 與 **English** 之間即時切換,選擇會被記住;第一次開啟時,依瀏覽器或系統的語言決定。還沒儲存、仍使用預設名稱(「未命名」、"Untitled")的文件,會跟著改成對應語言的名稱。

### 寫文件與檢視

| 想做的事 | 怎麼做 |
|---|---|
| 新增文件 | 工具列「新增」,或分頁列右邊的「＋」 |
| 切換檢視 | 工具列「編輯 / 分割 / 預覽」;分割時可勾選「同步捲動」 |
| 在文件間切換、關閉 | 點上方分頁;分頁上的「×」關閉(有未儲存內容會先詢問) |
| 搜尋與取代 | 「搜尋／取代」或 `Ctrl+F` |
| 復原 / 重做 | 工具列按鈕,或 `Ctrl+Z`、`Ctrl+Y` |
| 跳到某個標題 | 左側「側欄」的「大綱」,點標題即可 |

分頁標題前面的 **●** 表示這份文件還沒儲存。

### 開啟與儲存

- **開啟**:選一個 `.md`、`.markdown` 或 `.txt` 檔。已經開著的檔案會直接切換過去,不會蓋掉你的修改
- **儲存**:`Ctrl+S`;**另存新檔**:`Ctrl+Shift+S`
- **最近文件**:側欄列出最近開過的檔案,點一下就能再開
- **自動儲存**:在右側「外觀設定」最下方開啟,設定間隔秒數。只會寫回已經存在的檔案,新文件請先手動存一次

### 換外觀

右側「外觀設定」可以:

- 從「主題」下拉選單切換 7 種內建主題
- 調整六種顏色、字型、字級、行距、段落間距、內容寬度、標題大小
- 在「自訂主題」輸入名稱後按「儲存為新主題」,之後可更新、重新命名、複製、刪除

沒看到設定面板時,按工具列的「外觀設定」。

### 匯出

按工具列「**匯出**」,選格式,確認檔名後按下按鈕:

| 格式 | 說明 |
|---|---|
| **Word (.docx)** | 保留標題、清單、表格、連結、程式碼與圖片 |
| **PDF** | 可設定紙張(A4、Letter、自訂)、方向、邊距、頁碼、頁首頁尾。按「開啟列印對話框」後,在「目的地」選「**另存為 PDF**」 |
| **HTML** | 單一網頁檔,樣式與圖片都包含在內 |
| **純文字 (.txt)** | 去掉 Markdown 標記的可讀文字 |

- 匯出前可以先看預覽,畫面也會提醒哪些內容無法完整轉換
- 「**匯出專用樣式**」會用白底深色字,即使你正在用夜間主題,印出來也不會是黑底;也可以改選「跟隨目前主題」
- 匯出不會動到原始文件,也不會覆蓋它

### 匯入

按工具列「**匯入**」,選擇 `.html` 或 `.docx` 檔。內容會轉成 Markdown,開在一份**新的**文件裡,並顯示轉換報告,說明有哪些內容(例如樣式、合併儲存格)沒有轉過來。原始檔案不會被修改。

### 圖片

文件裡用相對路徑引用的圖片(例如 `![說明](./images/cat.png)`),需要告訴程式圖片放在哪裡:

1. 在左側「側欄」的「**圖片資料夾**」按「選擇圖片資料夾…」
2. 選擇圖片所在的資料夾(程式只會讀取,而且只能讀到這個資料夾裡的檔案)
3. 預覽立刻會顯示圖片;匯出 Word、HTML、PDF 時也會一併放進去

支援 PNG、JPEG、GIF、WebP。外部網址的圖片為了保護隱私不會載入。每份文件的圖片資料夾各自設定,重新開啟後需要再選一次。

### 快捷鍵

| 動作 | 按鍵 |
|---|---|
| 儲存 / 另存新檔 | `Ctrl+S` / `Ctrl+Shift+S` |
| 復原 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 搜尋與取代 | `Ctrl+F` |
| 找下一個 | `F3` |
| 關閉對話框 | `Esc` |

完整清單在工具列「快捷鍵」。

## 常見問題

**雙擊後沒有出現視窗?** 請等 5–10 秒。仍然沒有的話,可以打開瀏覽器,在網址列輸入 `http://127.0.0.1:47831`。

**關掉視窗後,我的設定與「最近文件」不見了?** 它們存在瀏覽器裡。請一律用 `MarkFlowStudio.exe` 開啟,不要換成別的瀏覽器開網址。

**圖片沒有顯示?** 用側欄「圖片資料夾」選擇圖片所在的資料夾。

**PDF 的頁碼沒有出現?** 頁碼、頁首、頁尾需要 Chrome 或 Edge 131 以上的版本。

**程式出問題了?** 記錄檔在 `%LOCALAPPDATA%\MarkFlowStudio\launcher.log`(貼到檔案總管的網址列即可開啟)。

**怎麼移除?** 壓縮檔版直接刪除資料夾即可,程式沒有安裝任何東西到系統;安裝程式版請從 Windows「已安裝的應用程式」解除安裝。
