# 格式支援矩陣

最後更新:Phase 8(圖片、重構之後)。狀態以自動化測試與實際檢查為準;「未驗證」表示沒有在真實環境確認過。

## 總覽

| 格式 | 開啟／匯入 | 儲存／匯出 | 備註 |
|---|---|---|---|
| Markdown `.md` `.markdown` | ✅ 開啟 | ✅ 儲存／另存 | 嚴格 UTF-8,上限 5 MB |
| 純文字 `.txt` | ✅ 開啟(視為 Markdown) | ✅ 匯出(去除標記) | |
| HTML `.html` `.htm` | ✅ 匯入 → Markdown | ✅ 匯出 | |
| PDF `.pdf` | ❌ | ⚠️ 經由瀏覽器列印 | 程式不產生 PDF 檔;僅在 Chrome 155/Windows 驗證過,其他環境未驗證 |
| Word `.docx` | ✅ 匯入 → Markdown | ✅ 匯出 | |
| `.doc` `.rtf` `.odt` `.epub` `.tex` `.xml` | ❌ 會明確拒絕 | ❌ | 尚未支援,不會假裝轉換 |

匯入的結果一律開成**尚未儲存的新文件**,不會覆寫來源檔。副檔名與實際內容不符(例如把 zip 改名成 `.html`)會被拒絕。

## 匯出

### HTML(`exporters/html.ts`)
| 項目 | 狀態 |
|---|---|
| 標題、段落、強調、刪除線 | ✅ |
| 清單(含巢狀)、引用、分隔線 | ✅ |
| 表格、程式碼區塊(含語言 class) | ✅ |
| 連結 | ✅ 僅 http(s)／mailto 等安全協定 |
| 圖片 | ✅ 在側欄選擇「圖片資料夾」後,相對路徑圖片(PNG、JPEG、GIF、WebP)會內嵌為資料 URI;讀不到的圖片保留原路徑並警告;外部網址圖片保持原樣(開啟時需連網) |
| 腳本 | 🚫 不含任何腳本;內嵌 CSP `default-src 'none'` |
| 樣式 | ✅ 內嵌 CSS,可選「匯出專用(白底)」或「跟隨主題」 |

### TXT(`exporters/txt.ts`)
標題、強調等標記會移除;清單保留縮排與編號;程式碼逐字保留;引用加 `> `;連結附上網址;表格以 ` | ` 分隔。圖片改為替代文字(會警告)。

### PDF(`exporters/pdf.ts`、`print.ts`)— 瀏覽器列印
產生為列印排版的 HTML,由瀏覽器列印為 PDF。**app 無法取得或驗證使用者最終存下的 PDF。** 頁碼／頁首／頁尾僅 Chrome／Edge 131+。已讀到的本機圖片(經圖片資料夾)會內嵌;其餘圖片(讀不到的、外部網址)改為「[圖片:說明]」文字。已在 Chrome 155(Windows,headless)驗證列印結果(見 `docs/TESTING.md`)。

### DOCX(`exporters/docx/`)
| 項目 | 狀態 | 備註 |
|---|---|---|
| 標題 H1–H6 | ✅ | 對應 Word 標題樣式,字級／顏色取自主題 |
| 粗體、斜體、刪除線、行內程式碼 | ✅ | |
| 超連結 | ✅ | 僅 http(s)／mailto;其餘以純文字呈現 |
| 項目清單、有序清單、巢狀 | ✅ | 每個有序清單獨立重新編號;**自訂起始編號不保留**(會警告) |
| 表格 | ✅ | 表頭加粗、跨頁重複表頭、列不被切斷、保留欄位對齊 |
| 程式碼區塊 | ✅ | 等寬字型、灰底、保留縮排;**語言標籤不保留**、無語法上色 |
| 引用、分隔線 | ✅ | |
| 圖片 | ✅ | 經「圖片資料夾」讀到的 PNG／JPEG／GIF 以 `ImageRun` 嵌入,超過頁寬(600 px)或頁高(800 px)時等比縮小、不放大;**WebP 不支援**(Word 沒有該格式),讀不到的圖片、外部網址圖片改為「[圖片:說明]」文字,都會警告 |
| 頁面背景色 | ❌ | 不套用(會警告);文字與標題顏色會套用 |
| 頁面設定 | ⚠️ | 固定 A4、約 25 mm 邊距,尚無頁碼／頁首頁尾 |

驗證:產生後檢查 zip 簽章、`[Content_Types].xml`、`word/document.xml`;測試解開封裝檢查 XML 內容(標題樣式、超連結關聯、編號、表格、字型)。**未驗證**:用真實 Word／LibreOffice 開啟的外觀。

## 匯入

### HTML → Markdown(`importers/html.ts`)
輸入視為不可信:先以 DOMParser 檢查(不插入頁面),再經 DOMPurify 消毒,最後用 Turndown 轉換。

| 項目 | 狀態 |
|---|---|
| 標題、段落、強調、刪除線、連結、清單、引用、分隔線 | ✅ |
| 程式碼區塊 | ✅ 保留 `language-*` |
| 表格 | ✅ 轉為 GFM 表格;`\|` 會跳脫 |
| 合併儲存格(colspan／rowspan)、巢狀表格 | ⚠️ 資訊遺失(會警告) |
| `script`、`style`、`iframe`、`svg`、`video`、表單等 | 🚫 移除並計數警告 |
| 行內樣式、顏色、字型 | ❌ 不轉換(會警告) |
| `javascript:` 連結、事件屬性 | 🚫 移除 |
| 內嵌 `data:` 圖片 | ❌ 不匯入,改為文字說明(會警告) |
| 相對路徑圖片 | ⚠️ 保留語法,但預覽不會載入(會警告) |
| 編碼 | 僅 UTF-8;其他編碼(如 Big5)會被拒絕,請先轉成 UTF-8 |

上限 5 MB。

### DOCX → Markdown(`importers/docx.ts`,使用 mammoth)
| 項目 | 狀態 |
|---|---|
| 標題、段落、粗體／斜體／刪除線、連結、清單、表格 | ✅(往返測試涵蓋) |
| 圖片 | ❌ 不匯入並警告 |
| 頁首頁尾、欄位、文字方塊、註解、追蹤修訂、字型、顏色 | ❌ 不轉換(每次都會提示) |
| mammoth 自己的轉換訊息(未知樣式等) | ⚠️ 原文列入報告(英文) |
| 舊版 `.doc` | ❌ 拒絕 |

安全:上限 20 MB;檢查 zip 簽章與 `word/document.xml`;依封存檔宣告的解壓縮大小做**盡力而為**的炸彈防護(上限 200 MB,宣告值可被偽造,故非完整保證)。
